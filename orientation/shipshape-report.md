## What "pass" means

Each category is keyed to a PRD threshold from the Phase 2 brief. The orchestrator
exits nonzero if **any** category regresses below its threshold, so `pnpm shipshape`
is suitable as a release gate.

`SKIP` is reserved for environment problems (e.g. dev:web not running for the axe
scan) — it does not contribute to pass/fail, but is surfaced in the scoreboard so
the operator can rerun the check after fixing the environment.
