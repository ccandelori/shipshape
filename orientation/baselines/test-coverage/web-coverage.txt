## Methodology

1. `pnpm --filter @ship/web test` first, to confirm parity-fix counts: 16 files, 151 tests, 0 failures.
2. `pnpm --filter @ship/web test --coverage` to emit the v8 reporter table.
3. Coverage scope is bound by `web/vitest.config.ts` (configured in a prior session with `coverage: { provider: 'v8', ... }`).

Caveats:
- v8 coverage measures *instrumented file execution*, not behavioral correctness. A line marked covered can still have an unasserted-branch bug.
- The web/ tests are not part of the headline `pnpm test` script in `package.json:33` — that runs only `@ship/api`. The Phase 2 "CI" improvement (Taskmaster #17) should add `pnpm --filter @ship/web test` to CI to keep this coverage number live.
- The vitest 4.0.17 ↔ @vitest/coverage-v8 4.0.18 minor-version drift produces a one-line warning at startup. We pinned `~4.0.17` to avoid the 4.1.x family that broke against vitest 4.0.x; the 4.0.18 patch is the closest minor that resolves. Output is unaffected.
